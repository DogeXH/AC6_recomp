AC6 Recomp with netplay, Windows x64 build: third-party notices
================================================================

ac6recomp.exe is a single statically linked program. Besides the AC6 Recomp code itself
(see LICENSE.txt, BSD 3-Clause, kept as published upstream), it contains the third-party
components listed below. The full license text of each one is in the licenses/ folder next
to this file. Versions are those of the source copies the exe was built from; where a commit
is given, every compiled file of the vendored copy was checked byte-identical to that upstream
commit.

No game assets, disc image or XEX are included. ac6recomp.exe contains code recompiled from the
game executable, as upstream AC6 Recomp's releases do; you need your own copy of the game.

- The exact source of both libraries as built is in the AC6 Recomp source tree, directories

  These directories are identical to upstream AC6 Recomp
  https://github.com/sal063/AC6_recomp at commit 5d350c293a984b6a4e11c2759f1d09472c50a87e.

  available at:
  Source for this build: https://github.com/DogeXH/AC6_recomp/tree/netplay-online (commit 7d841e65)
- To relink with a modified FFmpeg or libmspack: get that source, replace the library's
  directory with your modified version, generate the recompiled game code from your own copy
  of the game (it is generated from your own copy of the game executable), and build

  setup_and_build.bat on Windows). The AC6 Recomp license permits modification and reverse
  engineering for debugging such modifications.

3. Regenerating this file
-------------------------

netplay/release/update_licenses.sh [build dir] refreshes licenses/ from the source tree,
lists the libraries on the ac6recomp.exe link line (and warns about unknown ones) and prints
the version macros. See "Release notices" in netplay/docs/BUILDING_WINDOWS.md.
