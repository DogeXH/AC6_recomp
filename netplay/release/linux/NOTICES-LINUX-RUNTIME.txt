AC6 Recomp Online for Linux: the bundled C runtime
=================================================

This applies to the Linux package only. THIRD_PARTY_NOTICES.txt covers the libraries compiled
into the game itself.

GNU C Library (glibc) 2.44
--------------------------

Files: ld-linux-x86-64.so.2 and lib/ (libc, libm, libmvec, libdl, libpthread, librt,
libresolv, libutil, libanl). They are copied unmodified from Arch Linux's glibc package
2.44+r50+g1848099f063e-1, which the Linux build was compiled against. They are bundled because
the game needs glibc 2.44 and most systems, SteamOS 3.8 included, have an older one; the game
starts through this loader (ac6recomp.sh) and does not change your system's glibc.

License: GNU Lesser General Public License, version 2.1 or later (licenses/glibc-COPYING.LIB.txt),
with the additional notices in licenses/glibc-LICENSES.txt.

Source: the complete source of this glibc is published next to this package on the same release
page, as glibc-2.44-1848099f063e-source.tar.gz. It is the upstream glibc tree at commit
1848099f063e99d4ffecbd7667766d54862398b9 (https://sourceware.org/git/glibc.git), which Arch
builds with no source patches. Arch's build recipe is in licenses/glibc-arch-PKGBUILD.txt. You
may replace these files with your own build of glibc 2.44 or later.

GCC runtime libraries (libstdc++, libgcc)
-----------------------------------------

The game links GCC's libstdc++ statically (Arch's gcc-libs 16.2.1+r23+gd564253eb6c8-1), under
the GNU General Public License version 3 with the GCC Runtime Library Exception 3.1
(licenses/GPL-3.0.txt, licenses/GCC-exception-3.1.txt), which permits distributing the combined
program under its own terms. libgcc is not included: the game uses your system's libgcc_s.so.1,
which every Linux system has.
